# ULTEAMMATE Builder
A blender plugin for streamlined creation of procedural building.

The plugin sets up an asset library named "ULTEAMMATE" by default.
You can change the path of the library in addon settings, otherwise Blender's default user library locatin will be used.
If addon cannot find asset librayr, settings panel will not display regular settings, but will guide user to preferences,
to setup asset library properly.
